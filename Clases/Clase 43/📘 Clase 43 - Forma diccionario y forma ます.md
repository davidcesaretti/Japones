

Una de las partes centrales fue seguir practicando la conjugación de verbos.

### Idea clave

Los verbos se estudian desde dos formas muy importantes:

- **forma diccionario**
- **forma masu**

### Ejemplos

- **kiku** → **kikimasu**  
    聞く → 聞きます  
    = escuchar
- **hanasu** → **hanashimasu**  
    話す → 話します  
    = hablar
- **iku** → **ikimasu**  
    行く → 行きます  
    = ir
- **kuru** → **kimasu**  
    来る → 来ます  
    = venir
