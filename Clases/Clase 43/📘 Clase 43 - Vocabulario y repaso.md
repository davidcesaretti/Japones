### Palabras útiles mencionadas

- **uchi** (うち / 家) = casa
- **gohan** (ごはん / ご飯) = comida / arroz
- **ginkou** (ぎんこう / 銀行) = banco
- **toshokan** (としょかん / 図書館) = biblioteca
- **mise** (みせ / 店) = tienda
- **ongaku** (おんがく / 音楽) = música
- **terebi** (テレビ) = televisión
- **zasshi** (ざっし / 雑誌) = revista
- **koohii** (コーヒー) = café
