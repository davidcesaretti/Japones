

Uno de los temas centrales fue la práctica de **posiciones** para describir dónde está algo.

### Vocabulario importante

- **hidari** (ひだり / 左) = izquierda
- **migi** (みぎ / 右) = derecha
- **mannaka** (まんなか / 真ん中) = centro / medio
- **ue** (うえ / 上) = arriba
- **shita** (した / 下) = abajo
- **tonari** (となり / 隣) = al lado
- **mae** (まえ / 前) = delante
- **ushiro** (うしろ / 後ろ) = detrás
