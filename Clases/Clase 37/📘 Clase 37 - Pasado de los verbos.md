

Una de las partes centrales fue el uso del **pasado**.

### Regla básica

- **〜ます** → presente / futuro
- **〜ました** → pasado afirmativo

### Ejemplos

- **ikimasu** = voy / iré
- **ikimashita** = fui
- **mimasu** = veo / veré
- **mimashita** = vi
- **kaimasu** = compro / compraré
- **kaimashita** = compré
