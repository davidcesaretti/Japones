

El resumen dice que vieron pasado de verbo y adjetivos, incluyendo diferencia entre **i** y **na**.

### Afirmativo pasado

- **〜い** → **〜かったです**

### Ejemplos

- **yasui desu** = es barato
- **yasukatta desu** = era / fue barato
- **isogashii desu** = está ocupado
- **isogashikatta desu** = estuvo ocupado
- **omoshiroi desu** = es interesante
- **omoshirokatta desu** = fue interesante

### Negativo

- **〜くないです** = no es...
- **〜くなかったです** = no era / no fue...

### Ejemplos

- **yasukunai desu** = no es barato
- **yasukunakatta desu** = no era barato
