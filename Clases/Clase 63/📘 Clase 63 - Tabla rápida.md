

|Interrogativo|+ か|+ も + negativo|
|---|---|---|
|何 nani|何か nanika = algo|何も nanimo = nada|
|誰 dare|誰か dareka = alguien|誰も daremo = nadie|
|どこ doko|どこか dokoka = algún lugar|どこにも dokonimo = ningún lugar|

### Ejemplos con どこ

- **dokoka ni ikimasu**  
    どこかに行きます。  
    = voy a algún lugar.
    
- **dokonimo ikimasen**  
    どこにも行きません。  
    = no voy a ningún lado.
