

## は

Marca el tema.

- **Robert-san wa...**

## が

Puede identificar el sujeto, especialmente cuando preguntamos **quién**.

- **dare ga...?**

## を

Marca el objeto directo.

- **nani o tabemashita ka**

## か

Con interrogativos puede producir palabras indefinidas.

- **dareka** = alguien
- **nanika** = algo

## も

Con interrogativos y una oración negativa puede expresar negación total.

- **daremo + negativo** = nadie
- **nanimo + negativo** = nada
