

El pasado negativo informal se forma desde **〜ない**.

### Regla

**〜ない → 〜なかった**

### Ejemplos

- **tabenai** → **tabenakatta**  
    食べない → 食べなかった  
    = no comió / no comí
    
- **ikanai** → **ikanakatta**  
    行かない → 行かなかった  
    = no fue / no fui
    
- **shinai** → **shinakatta**  
    しない → しなかった  
    = no hizo / no hice
    
- **kawanai** → **kawanakatta**  
    買わない → 買わなかった  
    = no compró / no compré
