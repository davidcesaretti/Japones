

Para los verbos del grupo 1, la sílaba final de la forma diccionario pasa de la fila **u** a la correspondiente fila **a**, y después se agrega **ない**.

## Cambios principales

- **く → かない**
- **ぐ → がない**
- **す → さない**
- **つ → たない**
- **ぬ → なない**
- **ぶ → ばない**
- **む → まない**
- **る → らない**

### Ejemplos

- **kaku** → **kakanai**  
    書く → 書かない  
    = no escribir
- **oyogu** → **oyoganai**  
    泳ぐ → 泳がない  
    = no nadar
- **hanasu** → **hanasanai**  
    話す → 話さない  
    = no hablar
- **matsu** → **matanai**  
    待つ → 待たない  
    = no esperar
- **yomu** → **yomanai**  
    読む → 読まない  
    = no leer
- **asobu** → **asobanai**  
    遊ぶ → 遊ばない  
    = no jugar
- **kaeru** → **kaeranai**  
    帰る → 帰らない  
    = no regresar
