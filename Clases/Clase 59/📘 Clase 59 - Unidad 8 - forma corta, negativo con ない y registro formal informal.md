

## Forma larga y forma corta

Uno de los temas centrales de esta clase fue la diferencia entre las formas que ya venían usando con **〜ます / です** y la nueva **forma corta**.

### Forma larga / cortés

Es la forma que vienen usando habitualmente:

- **tabemasu** = como
- **nomimasu** = bebo
- **ikimasu** = voy
- **tabemasen** = no como
- **nomimasen** = no bebo

### Forma corta

La forma corta utiliza directamente la forma diccionario o sus conjugaciones cortas:

- **taberu** = comer / como
- **nomu** = beber / bebo
- **iku** = ir / voy
- **tabenai** = no comer / no como
- **nomanai** = no beber / no bebo

### Comparación

|Forma larga|Forma corta|Significado|
|---|---|---|
|食べます — tabemasu|食べる — taberu|comer|
|飲みます — nomimasu|飲む — nomu|beber|
|行きます — ikimasu|行く — iku|ir|
|食べません — tabemasen|食べない — tabenai|no comer|
|飲みません — nomimasen|飲まない — nomanai|no beber|
