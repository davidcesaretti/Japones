

### Lista principal

- **高い** takai = alto / caro
- **元気** genki = alegre / sano / bien
- **新しい** atarashii = nuevo
- **古い** furui = viejo / antiguo
- **暑い** atsui = caluroso
- **寒い** samui = frío
- **大きい** ookii = grande
- **小さい** chiisai = pequeño
- **楽しい** tanoshii = divertido
- **面白い** omoshiroi = interesante
- **つまらない** tsumaranai = aburrido
- **難しい** muzukashii = difícil
- **やさしい** yasashii = amable / gentil
- **怖い** kowai = aterrador
- **いい** ii = bueno
- **好き** suki = gustar / que gusta
- **嫌い** kirai = no gustar / que no gusta
