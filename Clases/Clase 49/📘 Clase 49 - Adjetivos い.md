

Son los adjetivos que terminan en **い** en su forma básica.

### Ejemplos

- **takai** (たかい / 高い) = alto / caro
- **atarashii** (あたらしい / 新しい) = nuevo
- **furui** (ふるい / 古い) = viejo / antiguo
- **atsui** (あつい / 暑い) = caluroso
- **samui** (さむい / 寒い) = frío
- **ookii** (おおきい / 大きい) = grande
- **chiisai** (ちいさい / 小さい) = pequeño
- **tanoshii** (たのしい / 楽しい) = divertido
- **omoshiroi** (おもしろい / 面白い) = interesante
- **muzukashii** (むずかしい / 難しい) = difícil
- **kowai** (こわい / 怖い) = aterrador / da miedo
- **tsumaranai** (つまらない) = aburrido
- **yasashii** (やさしい / 優しい) = amable / gentil
