

- **kakimasu** (かきます / 書きます) = escribir

- **ikimasu** (いきます / 行きます) = ir
- **mimasu** (みます / 見ます) = ver
- **kaimasu** (かいます / 買います) = comprar
- **shimasu** (します) = hacer
- **asobimasu** o según contexto actividad = jugar
- **tabemasu** (たべます / 食べます) = comer
