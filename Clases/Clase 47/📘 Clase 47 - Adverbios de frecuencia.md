

Se mencionó que ya vieron adverbios de frecuencia.

### Algunos útiles

- **itsumo** (いつも) = siempre
- **tokidoki** (ときどき / 時々) = a veces
- **yoku** (よく) = a menudo
- **amari** (あまり) = no muy, no tanto
- **zenzen** (ぜんぜん) = nada / para nada, con negativo

### Ejemplos

- **tokidoki eiga o mimasu**  
    = a veces veo películas
- **amari terebi o mimasen**  
    = no miro mucha televisión
