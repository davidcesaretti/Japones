

### Comidas

- **taiyaki** (たいやき / 鯛焼き) = pastelito con forma de pez
- **anko** (あんこ) = pasta dulce de porotos / frijol azucarado
- **korokke** (コロッケ) = croqueta
- **shuumai / shumai** (しゅうまい / 焼売) = shumai
- **nori** (のり / 海苔) = alga nori
- **konbu** (こんぶ / 昆布) = alga kombu
- **tarako** (たらこ / 鱈子) = huevas de pescado
- **ume** (うめ / 梅) = ume, fruto japonés muy ácido
