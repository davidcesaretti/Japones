

Una parte importante fue preguntar por disponibilidad de colores.

### Colores útiles

- **aka** (あか / 赤) = rojo
- **ao** (あお / 青) = azul

### Color + sustantivo

- **aka no T-shatsu** = remera roja
- **ao no T-shatsu** = remera azul

### Idea importante

Se remarcó la diferencia entre:

- usar el color como **sustantivo**
- usar el color para **describir** un objeto

Por eso salen estructuras como:

- **aka no**
- **ao no**

## Preguntar por otros colores

### Estructura útil

- **hoka no iro wa arimasu ka**  
    ほかの色はありますか  
    = ¿Hay otros colores?

### Elegir una opción

- **jaa, ao o kudasai**  
    じゃあ、青をください  
    = Entonces, deme el azul
