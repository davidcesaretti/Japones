

La clase siguió trabajando el **pasado informal** de los verbos con la forma **た**.

### Ejemplos

- **taberu** → **tabeta**  
    食べる → 食べた  
    = comió / comí
    
- **miru** → **mita**  
    見る → 見た  
    = vio / vi
    
- **iku** → **itta**  
    行く → 行った  
    = fue / fui
    
- **suru** → **shita**  
    する → した  
    = hizo / hice
