

También apareció la forma negativa en pasado.

La estructura es:

**〜ない → 〜なかった**

### Ejemplos

- **tabenai** → **tabenakatta**  
    食べない → 食べなかった  
    = no comió / no comí
    
- **ikanai** → **ikanakatta**  
    行かない → 行かなかった  
    = no fue / no fui
    
- **benkyou shinai** → **benkyou shinakatta**  
    勉強しない → 勉強しなかった  
    = no estudió / no estudié
    

### Idea clave

Para formar el pasado negativo informal:

- negativo presente: **〜ない**
- pasado negativo: **〜なかった**
