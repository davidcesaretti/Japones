

### Transporte

- **takushii** (タクシー) = taxi
- **basu** (バス) = colectivo / autobús
- **kuruma** (くるま / 車) = auto

### Lugares de ciudad

- **yuubinkyoku** (ゆうびんきょく / 郵便局) = correo / oficina de correos
- **ginkou** (ぎんこう / 銀行) = banco
- **hoteru** (ホテル) = hotel
- **resutoran** (レストラン) = restaurante
- **otera** (おてら / お寺) = templo budista

### Orientación / direcciones

- **migi** (みぎ / 右) = derecha
- **hidari** (ひだり / 左) = izquierda
- **massugu** (まっすぐ) = derecho / recto
- **koko** (ここ) = acá
- **soko** (そこ) = ahí
- **asoko** (あそこ) = allá

### Verbos relacionados

- **ikimasu** (いきます / 行きます) = ir
- **magarimasu** (まがります / 曲がります) = doblar / girar
- **tomarimasu** (とまります / 止まります) = parar / detenerse
