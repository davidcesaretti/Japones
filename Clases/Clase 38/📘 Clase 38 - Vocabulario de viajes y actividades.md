

### Lugares

- **Toukyou** (とうきょう / 東京) = Tokio
- **Kyouto** (きょうと / 京都) = Kioto
- **Hiroshima** (ひろしま / 広島) = Hiroshima
- **Nagasaki** (ながさき / 長崎) = Nagasaki
- **tera** / **o-tera** (てら / お寺) = templo
- **kouen** (こうえん / 公園) = parque

### Cultura

- **kabuki** (かぶき / 歌舞伎) = kabuki
- **matsuri** (まつり / 祭り) = festival

### Compras

- **omiyage** (おみやげ / お土産) = souvenir / regalo de viaje

## Comida

### Palabras vistas

- **soba** (そば) = fideos soba
- **udon** (うどん) = fideos udon
- **sushi** (すし) = sushi
- **hashi** (はし / 箸) = palillos
- **aisu kuriimu** (アイスクリーム) = helado

### Ejemplos

- **Toukyou de soba o tabemashita**  
    東京でそばを食べました  
    = comí soba en Tokio
- **udon o tabemashita**  
    うどんを食べました  
    = comí udon
- **sushi o tabemashita**  
    すしを食べました  
    = comí sushi
