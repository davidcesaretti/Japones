

### Hacer

- **shimasu** = hago / haré
- **shinai** = no hago / no haré

### Querer hacer

- **shitai** = quiero hacer
- **shitakunai desu** = no quiero hacer

### Ejemplos

- **benkyou shimasu**  
    勉強します  
    = estudio / voy a estudiar
- **benkyou shinai**  
    勉強しない  
    = no estudio / no voy a estudiar
- **benkyou shitai desu**  
    勉強したいです  
    = quiero estudiar
- **benkyou shitakunai desu**  
    勉強したくないです  
    = no quiero estudiar
