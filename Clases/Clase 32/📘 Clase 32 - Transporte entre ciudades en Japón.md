

Aparecieron varias opciones para ir de una ciudad a otra.

### Medios mencionados

- **shinkansen** (しんかんせん / 新幹線) = tren bala
- **hikouki** (ひこうき / 飛行機) = avión
- **basu** (バス) = colectivo / autobús
- colectivo nocturno como opción económica

### Idea importante

El colectivo nocturno fue presentado como una opción:

- más barata
- más lenta
- útil para ahorrar dinero
