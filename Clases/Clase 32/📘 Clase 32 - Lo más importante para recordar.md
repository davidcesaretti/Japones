

### Gramática

- **adjetivos i** van directo con el sustantivo
- **adjetivos na** necesitan **na** antes del sustantivo
- **takai** puede significar **alto** o **caro**

### Vocabulario

- **ookii** = grande
- **chiisai** = pequeño
- **atarashii** = nuevo
- **takai** = alto / caro
- **kirei** = limpio / lindo
- **nigiyaka** = concurrido / animado
- **biru** = edificio
- **kouen** = parque
- **kawa** = río
- **shiro** = castillo

### Cultura

- Osaka aparece como una ciudad muy buena para practicar descripción de lugares
- Dotonbori sirve como ejemplo ideal para **nigiyaka**
- los edificios sirven como ejemplo ideal para **takai**
