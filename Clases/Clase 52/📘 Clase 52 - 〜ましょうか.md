

En la clase también apareció una expresión transcripta como “mashoka”. La forma correcta es:

**〜ましょうか**  
**mashou ka**

### Significado

Se usa para:

- ofrecerse a hacer algo
- proponer ayuda
- preguntar “¿lo hago?”

### Ejemplo con equipaje

- **nimotsu o mochimashou ka**  
    にもつをもちましょうか  
    = ¿Le llevo el equipaje? / ¿Quiere que lleve el equipaje?

### Otros ejemplos

- **tetsudaimashou ka**  
    てつだいましょうか  
    = ¿Lo ayudo?
- **mado o akemashou ka**  
    まどをあけましょうか  
    = ¿Abro la ventana?

### Diferencia con 〜ませんか

- **〜ましょうか** = ¿lo hago? / ¿hacemos?
- **〜ませんか** = ¿no quiere hacer…? / ¿hacemos…?
