

Otra parte importante fue el uso de palabras para expresar frecuencia.

### Palabras útiles

- **totemo** (とても) = muy
- **tokidoki** (ときどき / 時々) = a veces
- **itsumo** (いつも) = siempre
- **amaini / amari** según contexto negativo = no muy / no tanto
- **mainichi** (毎日) = todos los días

### Ejemplos

- **tokidoki toshokan e ikimasu**  
    時々図書館へ行きます  
    = a veces voy a la biblioteca
- **mainichi koohii o nomimasu**  
    毎日コーヒーを飲みます  
    = tomo café todos los días
- **totemo isogashii desu**  
    とても忙しいです  
    = estoy muy ocupado
