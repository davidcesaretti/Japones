

La clase dejó como punto de repaso vocabulario de partes del cuerpo para poder hacer descripciones más completas.

### Algunas palabras importantes

- **kami** (かみ / 髪) = pelo
- **me** (め / 目) = ojo
- **hana** (はな / 鼻) = nariz
- **kuchi** (くち / 口) = boca
- **kao** (かお / 顔) = cara
- **atama** (あたま / 頭) = cabeza
- **te** (て / 手) = mano
- **ashi** (あし / 足) = pierna / pie
- **se** (せ / 背) = altura / estatura
