

## Vocabulario

### Regalos y objetos

- **omiyage** (おみやげ / お土産) = souvenir, regalo de viaje
- **hagaki** (はがき / 葉書) = postal
- **tokei** (とけい / 時計) = reloj
- **kasa** (かさ / 傘) = paraguas
- **hankachi** (ハンカチ) = pañuelo
- **shatsu** (シャツ) = camisa
- **tii shatsu / t-shatsu** (Tシャツ) = remera, camiseta
- **chokoreeto** (チョコレート) = chocolate
- **hana** (はな / 花) = flores
- **akusesarii** (アクセサリー) = accesorios
- **terebi** (テレビ) = televisor
- **mausu** (マウス) = mouse
