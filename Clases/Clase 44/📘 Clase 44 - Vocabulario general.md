

### Casa y lugares

- **uchi / ie** (うち / いえ / 家) = casa
- **resutoran** (レストラン) = restaurante
- **suupaa** (スーパー) = supermercado

### Personas / seres vivos

- **kodomo** (こども / 子ども) = niño
- **inu** (いぬ / 犬) = perro
- **neko** (ねこ / 猫) = gato

### Comida

- **tabemono** (たべもの / 食べ物) = comida
- **gohan** (ごはん / ご飯) = comida / arroz

## あります

Uno de los temas centrales fue el uso de **arimasu** para indicar existencia de cosas o ubicación de objetos.

### あります

- **arimasu** (あります) = hay / existe / está

Se usa para:

- cosas
- objetos
- lugares
- elementos no animados

### Ejemplos

- **isu ga arimasu**  
    いすがあります  
    = hay una silla
- **tsukue no ue ni hon ga arimasu**  
    つくえの上に本があります  
    = hay un libro arriba del escritorio
- **suupaa ga arimasu**  
    スーパーがあります  
    = hay un supermercado
