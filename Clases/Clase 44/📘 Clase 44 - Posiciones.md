### Palabras importantes

- **ue** (うえ / 上) = arriba
- **shita** (した / 下) = abajo
- **naka** (なか / 中) = adentro
- **soto** (そと / 外) = afuera
- **tonari** (となり / 隣) = al lado
- **mae** (まえ / 前) = delante
- **ushiro** (うしろ / 後ろ) = detrás
