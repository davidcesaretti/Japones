### いい

- **ii** (いい / 良い) = bueno

Aunque termina en い, se conjuga de forma especial.

### Conjugaciones

- **ii desu** = es bueno
- **yokunai desu** = no es bueno
- **yokatta desu** = fue bueno
- **yokunakatta desu** = no fue bueno

### Idea clave

No se dice:

- **iikunai** ❌
- **iikatta** ❌

Se usa la raíz **yo-**:

- **yokunai**
- **yokatta**
- **yokunakatta**
