

### Presente afirmativo

- **takai desu** = es caro
- **tanoshii desu** = es divertido

### Presente negativo

Regla:

- **〜い** → **〜くないです**

Ejemplos:

- **takakunai desu** = no es caro
- **tanoshikunai desu** = no es divertido

### Pasado afirmativo

Regla:

- **〜い** → **〜かったです**

Ejemplos:

- **takakatta desu** = era / fue caro
- **tanoshikatta desu** = era / fue divertido

### Pasado negativo

Regla:

- **〜い** → **〜くなかったです**

Ejemplos:

- **takakunakatta desu** = no era / no fue caro
- **tanoshikunakatta desu** = no era / no fue divertido
- **tsumaranakunakatta desu** = no era / no fue aburrido
