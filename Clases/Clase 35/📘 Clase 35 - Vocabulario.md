

### Ropa

- **wanpiisu** (ワンピース) = vestido / one-piece
- **jiinzu** (ジーンズ) = jeans
- **zubon** (ズボン) = pantalón
- **jaketto** (ジャケット) = chaqueta / jacket
- **sukaato** (スカート) = falda / skirt
- **shatsu** (シャツ) = camisa
- **kimono** (きもの / 着物) = kimono
- **futon** (ふとん / 布団) = futón

### Compras / plataformas

- **Mercari** = plataforma de compra/venta de usados en Japón
- **Booking** = alojamientos tipo hotel

### Lugares / contexto útil

- **eki** (えき / 駅) = estación
- **Toukyou** (とうきょう / 東京) = Tokio
