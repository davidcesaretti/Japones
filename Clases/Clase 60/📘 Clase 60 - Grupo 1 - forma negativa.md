

Para los verbos del grupo 1, la última sílaba pasa a la fila **a** y se agrega **ない**.

### Ejemplos trabajados

- **kaku** → **kakanai**  
    書く → 書かない  
    = no escribir
- **oyogu** → **oyoganai**  
    泳ぐ → 泳がない  
    = no nadar
- **matsu** → **matanai**  
    待つ → 待たない  
    = no esperar
- **yomu** → **yomanai**  
    読む → 読まない  
    = no leer
- **hanasu** → **hanasanai**  
    話す → 話さない  
    = no hablar
- **kaeru** → **kaeranai**  
    帰る → 帰らない  
    = no volver
