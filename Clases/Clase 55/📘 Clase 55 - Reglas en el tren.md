

La clase trabajó permisos y prohibiciones relacionadas con el transporte público.

## Verbos útiles

- **hanashimasu** (はなします / 話します) = hablar
- **denwa o kakemasu** (でんわをかけます / 電話をかけます) = hacer una llamada
- **urimasu** (うります / 売ります) = vender
- **tabemasu** (たべます / 食べます) = comer
- **nomimasu** (のみます / 飲みます) = beber
- **tsukaimasu** (つかいます / 使います) = usar
- **kikimasu** (ききます / 聞きます) = escuchar
