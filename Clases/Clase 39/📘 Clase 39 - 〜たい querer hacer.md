

También retomaron la estructura para expresar deseo o planes futuros.

### Regla

Raíz en ます + **たい**

### Ejemplos

- **ikitai** = quiero ir
- **mitai** = quiero ver
- **kaitai** = quiero comprar
- **shitai** = quiero hacer
- **tabetai** = quiero comer

### Negativo

- **ikitakunai desu** = no quiero ir
- **mitakunai desu** = no quiero ver
- **kaitakunai desu** = no quiero comprar
- **shitakunai desu** = no quiero hacer
