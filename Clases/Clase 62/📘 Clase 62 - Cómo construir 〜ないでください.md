

Primero hay que llevar el verbo a su **forma negativa corta ない**.

Después:

**〜ない + でください**

### Grupo 1

- **miru** no, porque es grupo 2.
- **iku** → **ikanai** → **ikanaide kudasai**
- **suu** → **suwanai** → **suwanaide kudasai**
- **hanasu** → **hanasanai** → **hanasanaide kudasai**
- **matsu** → **matanai** → **matanaide kudasai**

### Grupo 2

Se elimina **る** y se agrega **ない**.

- **miru** → **minai** → **minaide kudasai**
- **taberu** → **tabenai** → **tabenaide kudasai**
- **neru** → **nenai** → **nenaide kudasai**

### Irregulares

- **suru** → **shinai** → **shinaide kudasai**
- **kuru** → **konai** → **konaide kudasai**
