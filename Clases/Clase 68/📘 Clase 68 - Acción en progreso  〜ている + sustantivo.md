

También se puede utilizar **〜ている** dentro de una descripción.

### Ejemplo

- **zasshi o yonde iru hito**  
    雑誌を読んでいる人  
    = la persona que está leyendo una revista

Comparación:

- **zasshi o yomu hito**  
    = persona que lee revistas / que lee una revista
    
- **zasshi o yonde iru hito**  
    = persona que está leyendo una revista ahora
