

Trabajaron estructuras para hablar de:

- nombre
- profesión
- estudios

### Estructuras útiles

#### Nombre

- **Tanaka-san desu**  
    田中さんです  
    = es el señor / la señora Tanaka

#### Profesión

- **isha desu**  
    医者です  
    = es médico
- **gakusei desu**  
    学生です  
    = es estudiante

#### Estudios / especialidad

- **Nihongo o benkyou shite imasu**  
    日本語を勉強しています  
    = está estudiando japonés
