

- **kiru** (着る) = ponerse ropa
- **kiru** (切る) = cortar
- **utau** (歌う) = cantar
- **T-shatsu** (Tシャツ) = remera
- **ginkou** (銀行) = banco
- **Toukyou** (東京) = Tokio
- **kami** (髪) = pelo
- **se** (背) = altura
- **omou** (思う) = pensar / creer
