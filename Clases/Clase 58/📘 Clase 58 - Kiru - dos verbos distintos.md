

En la clase apareció **kiru**, y es un buen ejemplo porque hay dos verbos diferentes con la misma pronunciación.

### 着る — kiru

- significa **ponerse ropa / vestir**
- grupo 2

### 切る — kiru

- significa **cortar**
- grupo 1

Aunque se pronuncian igual, se conjugan distinto.

### Forma ます

- 着る → **kimasu**
- 切る → **kirimasu**

### Forma て

- 着る → **kite**
- 切る → **kitte**

Este tipo de diferencia se reconoce por el kanji, el contexto y la conjugación.
