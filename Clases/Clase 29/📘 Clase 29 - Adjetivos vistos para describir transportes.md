## 

En la práctica trabajaron adjetivos para opinar sobre un transporte o recomendar una opción.

### Adjetivos útiles

- **hayai** (はやい / 速い) = rápido
- **yasui** (やすい / 安い) = barato
- **takai** (たかい / 高い) = caro
- **benri** (べんり / 便利) = útil / conveniente
- **fuben** (ふべん / 不便) = inconveniente / poco práctico

### Ejemplos

- **kono densha wa hayai desu**  
    この電車は速いです  
    = este tren es rápido
- **kono basu wa yasui desu**  
    このバスは安いです  
    = este colectivo es barato
- **takushii wa takai desu**  
    タクシーは高いです  
    = el taxi es caro
- **chikatetsu wa benri desu**  
    地下鉄は便利です  
    = el subte es conveniente
- **kono basho wa fuben desu**  
    この場所は不便です  
    = este lugar es poco práctico
