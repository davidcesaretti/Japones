

### Medios de transporte

- **densha** (でんしゃ / 電車) = tren eléctrico
- **chikatetsu** (ちかてつ / 地下鉄) = subte / metro
- **basu** (バス) = colectivo / autobús
- **takushii** (タクシー) = taxi
- **hikouki** (ひこうき / 飛行機) = avión
- **jitensha** (じてんしゃ / 自転車) = bicicleta
- **kuruma** (くるま / 車) = auto

### Lugares relacionados

- **eki** (えき / 駅) = estación
- **kuukou** (くうこう / 空港) = aeropuerto
- **gakkou** (がっこう / 学校) = escuela
- **ie** (いえ / 家) = casa
- **kouen** (こうえん / 公園) = parque
- **hoteru** (ホテル) = hotel

### Aeropuertos mencionados

- **Haneda kuukou** (はねだくうこう / 羽田空港) = aeropuerto de Haneda
- **Narita kuukou** (なりたくうこう / 成田空港) = aeropuerto de Narita

> En la clase también comentaron que **Narita está lejos del centro de Tokio** y que **Haneda está más cerca**, como contexto cultural y turístico.
