

## Verbos terminados en う・つ・る

Cambian a:

**った**

### Ejemplos

- **kau** → **katta**  
    買う → 買った  
    = compró / compré
    
- **matsu** → **matta**  
    待つ → 待った  
    = esperó / esperé
    
- **toru** → **totta**  
    取る → 取った  
    = tomó / tomé

## Verbos terminados en む・ぶ・ぬ

Cambian a:

**んだ**

### Ejemplos

- **yomu** → **yonda**  
    読む → 読んだ  
    = leyó / leí
    
- **asobu** → **asonda**  
    遊ぶ → 遊んだ  
    = jugó / jugué
