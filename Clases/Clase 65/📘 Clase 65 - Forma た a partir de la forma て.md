

Una buena estrategia de estudio es memorizar los pares.

### て → た

- **kaite** → **kaita**
- **hanashite** → **hanashita**
- **tabete** → **tabeta**

### で → だ

- **yonde** → **yonda**
- **oyoide** → **oyoida**

### って → った

- **matte** → **matta**
- **totte** → **totta**
- **itte** → **itta**

Esto permite reutilizar casi todas las reglas que ya aprendiste para la forma て.
