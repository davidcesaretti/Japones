

La **forma た** representa el pasado afirmativo en forma corta.

### Ejemplos

- **kaku** → **kaita**  
    書く → 書いた  
    = escribió / escribí
    
- **yomu** → **yonda**  
    読む → 読んだ  
    = leyó / leí
    
- **matsu** → **matta**  
    待つ → 待った  
    = esperó / esperé
    
- **hanasu** → **hanashita**  
    話す → 話した  
    = habló / hablé
    
- **taberu** → **tabeta**  
    食べる → 食べた  
    = comió / comí
    
- **miru** → **mita**  
    見る → 見た  
    = vio / vi
