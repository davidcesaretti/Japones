

En esta clase siguieron repasando una de las bases más importantes del curso: cómo transformar oraciones entre:

- presente afirmativo
- presente negativo
- pasado afirmativo
- pasado negativo

### Verbos

#### Presente afirmativo

- **ikimasu** = voy / iré
- **tabemasu** = como / comeré
- **mimasu** = veo / veré
- **kaimasu** = compro / compraré
- **shimasu** = hago / haré

#### Presente negativo

- **ikimasen** = no voy / no iré
- **tabemasen** = no como / no comeré
- **mimasen** = no veo / no veré
- **kaimasen** = no compro / no compraré
- **shimasen** = no hago / no haré

#### Pasado afirmativo

- **ikimashita** = fui
- **tabemashita** = comí
- **mimashita** = vi
- **kaimashita** = compré
- **shimashita** = hice

#### Pasado negativo

- **ikimasen deshita** = no fui
- **tabemasen deshita** = no comí
- **mimasen deshita** = no vi
- **kaimasen deshita** = no compré
- **shimasen deshita** = no hice
