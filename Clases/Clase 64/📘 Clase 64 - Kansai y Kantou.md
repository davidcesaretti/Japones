

Estas dos palabras son especialmente útiles para entender regiones de Japón.

## 関西 — Kansai

- **関** = barrera / paso
- **西** = oeste

**Kansai** hace referencia a la región occidental en torno a ciudades como Osaka y Kioto.

## 関東 — Kantou

- **関** = barrera / paso
- **東** = este

**Kantou** es la región oriental donde se encuentra Tokio.

### Para memorizar

- Kan**sai** → 西 → oeste
- Kan**tou** → 東 → este
