

La clase incluyó un ejercicio de comprensión de un anuncio con información sobre actividades.

Para este tipo de ejercicios conviene primero localizar información específica:

- **いつ — itsu** = cuándo
- **どこ — doko** = dónde
- **何 — nani** = qué
- **だれ — dare** = quién
- horarios
- fechas
- lugares
- actividades

No hace falta entender absolutamente todas las palabras para obtener la información principal.
