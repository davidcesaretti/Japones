

### 北

- **kita** (きた) = norte
- lectura en compuestos: **hoku**

### Ejemplos

- **kita**  
    北  
    = norte
    
- **Hokkaidou**  
    北海道  
    = Hokkaidō
    
- **Touhoku**  
    東北  
    = Tōhoku / región noreste
    

### 東北

Se forma con:

- **東** = este
- **北** = norte

Por eso:

**東北 → Touhoku → noreste**
