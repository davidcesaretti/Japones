

### Direcciones

- **higashi** = este
- **nishi** = oeste
- **minami** = sur
- **kita** = norte

### Lugares y conceptos

- **yama** = montaña
- **kuchi** = boca
- **iriguchi** = entrada
- **deguchi** = salida
- **kuni** = país
- **gaikoku** = país extranjero
- **gaikokujin** = extranjero
- **toki** = tiempo / momento
- **ji** = hora
