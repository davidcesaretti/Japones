

### 東

- **higashi** (ひがし) = este
- lectura en compuestos: **tou**

Una forma mnemotécnica para recordarlo es relacionarlo con:

- **木** = árbol
- **日** = sol

La idea visual es el **sol saliendo por el este entre los árboles**.

### Ejemplos

- **higashi**  
    東  
    = este
    
- **Toukyou**  
    東京  
    = Tokio
    
- **Kantou**  
    関東  
    = región de Kantō
