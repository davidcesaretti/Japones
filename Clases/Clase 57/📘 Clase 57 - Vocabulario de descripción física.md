

### Partes del cuerpo

- **me** (め / 目) = ojo
- **kuchi** (くち / 口) = boca
- **kami** (かみ / 髪) = pelo
- **kao** (かお / 顔) = cara
- **se** (せ / 背) = altura / estatura

### Adjetivos útiles

- **ookii** (おおきい / 大きい) = grande
- **chiisai** (ちいさい / 小さい) = pequeño
- **nagai** (ながい / 長い) = largo
- **mijikai** (みじかい / 短い) = corto
- **takai** (たかい / 高い) = alto
- **hikui** (ひくい / 低い) = bajo

### Ejemplos

- **se ga takai desu**  
    背が高いです。  
    = es alto/a.
- **se ga hikui desu**  
    背が低いです。  
    = es bajo/a.
- **kami ga nagai desu**  
    髪が長いです。  
    = tiene el pelo largo.
