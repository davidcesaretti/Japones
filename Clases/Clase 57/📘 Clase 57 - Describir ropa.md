

En japonés se usan verbos distintos según qué parte del cuerpo lleva la ropa.

## 着ます — kimasu

**kimasu** (きます / 着ます) se usa principalmente para ropa de la parte superior del cuerpo.

### Ejemplos

- **T-shatsu o kimasu**  
    Tシャツを着ます。  
    = ponerse / usar una remera.
- **jaketto o kimasu**  
    ジャケットを着ます。  
    = ponerse / usar una campera.

---

## はきます — hakimasu

**hakimasu** (はきます) se usa principalmente para ropa de la cintura para abajo.

### Ejemplos

- **jiinzu o hakimasu**  
    ジーンズをはきます。  
    = ponerse / usar jeans.
- **zubon o hakimasu**  
    ズボンをはきます。  
    = ponerse / usar pantalones.
- **sukaato o hakimasu**  
    スカートをはきます。  
    = ponerse / usar una pollera.
